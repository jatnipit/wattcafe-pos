# 08: เก็บที่อยู่จัดส่งและเติมที่อยู่ล่าสุด

**What to build:** ร้านพิมพ์บ้านเลขที่บนหน้าจอออเดอร์ แล้วระบบจำไว้ให้ลูกค้ารายนั้นในออเดอร์ถัดไป โดยออเดอร์เก่ายังคงเห็นที่อยู่ ณ เวลาที่สั่ง

**Blocked by:** 05 — ยืนยันออเดอร์พร้อมสำเนาราคา และกันการแก้ทับกัน

**Status:** ready-for-agent

- [ ] พิมพ์บ้านเลขที่บนหน้าจอออเดอร์แล้วบันทึก → เก็บในออเดอร์และเป็นที่อยู่ล่าสุดของลูกค้า
- [ ] ลูกค้าเดิมสร้างออเดอร์ใหม่ → ที่อยู่ล่าสุดถูกเติมให้เป็นค่าเริ่มต้น
- [ ] แก้ที่อยู่ของลูกค้าภายหลัง → ออเดอร์เก่ายังแสดงสำเนาเดิม
- [ ] ข้อความที่ลูกค้าแนบที่อยู่มาไม่ถูกแกะเป็นที่อยู่โดยอัตโนมัติ
