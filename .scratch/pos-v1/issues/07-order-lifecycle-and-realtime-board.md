# 07: เดินสถานะออเดอร์ ยกเลิก ดูประวัติ และกระดานเรียลไทม์

**What to build:** ร้านไล่ออเดอร์จากรับแล้วถึงจัดส่งสำเร็จ ยกเลิกตามกติกา และเห็นกระดานอัปเดตเองขณะยืนอยู่หน้าเคาน์เตอร์ โดยทุกการเปลี่ยนสถานะมีร่องรอยว่าใครทำเมื่อไร

**Blocked by:** 05 — ยืนยันออเดอร์พร้อมสำเนาราคา และกันการแก้ทับกัน

**Status:** ready-for-agent

- [ ] Received → Preparing → Delivering → Delivered ทำงานตามลำดับ; ข้ามหรือย้อนได้ 409
- [ ] Staff ยกเลิกได้ถึง Preparing; ที่ Delivering ต้องเป็น Super Admin และต้องมีเหตุผล (ไม่มี → 422)
- [ ] ทุกการเปลี่ยนสถานะบันทึกสถานะก่อน–หลัง ผู้ทำ และเวลา
- [ ] กระดานแสดงออเดอร์ใหม่หรือสถานะใหม่ภายใน 5 วินาที และยังทำงานได้เมื่อ realtime หลุด (poll 30 วินาที)
- [ ] ออเดอร์ร่างที่ไม่ถูกยืนยันเกิน 24 ชั่วโมงกลายเป็น Expired และไม่ถูกนับยอดขาย
- [ ] Delivered, Cancelled และ Expired เปลี่ยนสถานะต่อไม่ได้
