# 09: บันทึกการชำระเงินและเวลาที่ชำระ

**What to build:** ร้านบันทึกวิธีจ่ายและกดว่าชำระแล้วพร้อมเวลาที่รับเงิน เพื่อให้ยอดขายอ้างอิงวันที่เงินเข้าจริง และมีร่องรอยว่าใครเปลี่ยนสถานะการชำระ

**Blocked by:** 05 — ยืนยันออเดอร์พร้อมสำเนาราคา และกันการแก้ทับกัน

**Status:** ready-for-agent

- [ ] บันทึกวิธีจ่าย (เงินสด/โอน) และเปลี่ยนเป็นชำระแล้วพร้อมเวลาที่ชำระ
- [ ] ทุกการเปลี่ยนสถานะการชำระมีประวัติผู้ทำ เวลา และสถานะก่อน–หลัง
- [ ] บันทึกจำนวนเงินที่รับและเลขอ้างอิงการโอนได้โดยไม่บังคับ
- [ ] ไม่มีพฤติกรรมคำนวณเงินทอน จ่ายบางส่วน หรือคืนเงิน
- [ ] ออเดอร์ที่ยกเลิกแล้วไม่ถูกนับยอดขายแม้จะเคยชำระแล้ว
