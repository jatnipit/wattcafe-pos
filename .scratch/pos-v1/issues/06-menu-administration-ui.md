# 06: จัดการเมนู กลุ่มตัวเลือก และคำเรียกจากหน้าจอ

**What to build:** Super Admin เพิ่มและแก้เมนู กลุ่มตัวเลือก ค่าตัวเลือก และคำเรียกได้เองจากหน้าจอ แล้วการจับคำครั้งถัดไปใช้ข้อมูลใหม่ทันทีโดยไม่ต้อง deploy

**Blocked by:** 04 — จับคำที่ตั้งราคาและสร้าง Draft Order พร้อมยอดเงิน

**Status:** ready-for-agent

- [ ] เพิ่มเมนู กลุ่มตัวเลือก ค่าตัวเลือก และคำเรียกจากหน้าจอ แล้วข้อความถัดไปจับได้ทันที
- [ ] คำเรียกที่ซ้ำ (แม้ต่างช่องว่างหรือตัวพิมพ์) ถูกปฏิเสธ
- [ ] ลบเมนูที่มีออเดอร์อ้างอิงแล้ว ประวัติยังแสดงชื่อเมนูเดิม
- [ ] Staff เรียก endpoint เหล่านี้ได้ 403
- [ ] ปิดเมนูแล้วไม่ถูกจับในข้อความใหม่ แต่ออเดอร์เก่าไม่เปลี่ยน
- [ ] กำหนดได้ว่ากลุ่มตัวเลือกบังคับเลือกหรือไม่ และเลือกได้กี่ค่าต่ำสุด–สูงสุด
