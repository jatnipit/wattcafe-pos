# 10: รายงานยอดขายรายวัน

**What to build:** Super Admin เห็นยอดขายของแต่ละวันตามวันที่เงินเข้าจริง พร้อมรายการออเดอร์ที่อธิบายยอดนั้นได้ และเห็นชัดว่าอะไรถูกตัดออกเพราะยกเลิกหรือหมดอายุ

**Blocked by:** 09 — บันทึกการชำระเงินและเวลาที่ชำระ; 07 — เดินสถานะออเดอร์ ยกเลิก ดูประวัติ และกระดานเรียลไทม์

**Status:** ready-for-agent

- [ ] ยอดขายรวมเฉพาะออเดอร์ที่ชำระแล้วและไม่ใช่ Cancelled หรือ Expired
- [ ] จัดกลุ่มตามวันที่ของเวลาที่ชำระในเขตเวลา Asia/Bangkok (ส่งวันจันทร์ จ่ายวันอังคาร → นับอังคาร)
- [ ] กรองตามวันที่และสถานะได้
- [ ] แสดงเลขที่ออเดอร์ เวลาสั่ง เวลาชำระ รายการ ยอดรวม สถานะ วิธีจ่าย และสถานะการชำระ
- [ ] ออเดอร์ร่าง ออเดอร์ยกเลิก และออเดอร์หมดอายุถูกแยกออกจากยอดอย่างชัดเจน
- [ ] แก้ราคาเมนูภายหลังไม่เปลี่ยนยอดของออเดอร์เก่า
