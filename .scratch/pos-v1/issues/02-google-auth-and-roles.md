# 02: เข้าสู่ระบบด้วย Google และแบ่งสิทธิ์ Staff/Super Admin

**What to build:** คนของร้านเข้าสู่ระบบด้วยบัญชี Google และเห็นเฉพาะสิ่งที่บทบาทอนุญาต คนนอกที่ล็อกอินสำเร็จแต่ไม่มีบัญชีในระบบถูกปฏิเสธตั้งแต่ประตูหน้า และการออกจากระบบทำให้ session เดิมใช้ไม่ได้

**Blocked by:** 01 — วางฐานระบบและพาข้อความ LINE ขึ้นกระดาน

**Status:** ready-for-agent

- [ ] ผู้ใช้ที่ไม่มีใน allowlist ล็อกอิน Google สำเร็จแต่เห็นหน้า "ไม่ได้รับอนุญาต" และเรียก API ใด ๆ ไม่ได้
- [ ] Staff เห็นกระดานออเดอร์ แต่เรียก endpoint จัดการเมนูได้ 403
- [ ] Super Admin เข้าได้ทั้งกระดานและหน้าจัดการ
- [ ] เรียก API ที่ต้องสิทธิ์โดยไม่มี session → 401
- [ ] ออกจากระบบแล้ว refresh token เดิมใช้ไม่ได้
- [ ] บทบาทอ่านจากฐานข้อมูลทุกครั้ง ไม่เชื่อ claim ที่อยู่ใน token
