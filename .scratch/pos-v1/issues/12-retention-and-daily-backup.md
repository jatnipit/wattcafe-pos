# 12: ลบข้อมูลตามอายุและสำรองฐานข้อมูลรายวัน

**What to build:** ระบบลบข้อมูลที่หมดอายุตามนโยบาย PDPA โดยไม่กระทบยอดขายของปีปัจจุบัน และมี dump ฐานข้อมูลรายวันที่กู้คืนได้จริง แม้ใช้แผนฟรีที่ไม่มี backup อัตโนมัติ

**Blocked by:** 09 — บันทึกการชำระเงินและเวลาที่ชำระ

**Status:** ready-for-agent

- [ ] งานตามเวลาลบข้อความเกิน 45 วัน ลูกค้าที่ไม่สั่งเกิน 6 เดือน และออเดอร์เกิน 1 ปี
- [ ] การลบไม่ทำให้ยอดขายของปีปัจจุบันเปลี่ยน
- [ ] GitHub Action dump ฐานข้อมูลรายวันและเก็บไฟล์ย้อนหลังได้ตามจำนวนวันที่กำหนด
- [ ] มีบันทึกวิธีกู้คืนจาก dump และระบุว่าแผนฟรีไม่มี backup อัตโนมัติ
- [ ] ทดสอบแบบ dry-run กับข้อมูลตัวอย่างแล้วรายงานจำนวนแถวที่จะถูกลบก่อนลบจริง
