# 01: วางฐานระบบและพาข้อความ LINE ขึ้นกระดาน

**What to build:** ข้อความที่ลูกค้าส่งเข้าช่องทาง LINE ถูกบันทึกและแสดงบนกระดานทันที โดยระบบปฏิเสธของปลอมและไม่เก็บซ้ำ — ใบนี้รวม bootstrap ของโปรเจกต์ (Supabase local, migration, test harness) และรันบนเครื่องเท่านั้น ยังไม่ deploy

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] POST ที่มีลายเซ็นถูกต้องและเป็น event ใหม่ → ข้อความถูกบันทึกพร้อมผู้ส่ง เวลา และแสดงบนกระดาน
- [ ] ลายเซ็นผิดหรือไม่มี header → 400 และไม่มีข้อมูลใดถูกเขียน
- [ ] event เดิมส่งซ้ำ → ตอบ 200 แต่ไม่มีข้อความหรือออเดอร์เพิ่ม
- [ ] ผู้ส่งที่ดึงโปรไฟล์ไม่ได้ → ข้อความยังถูกบันทึก โดยชื่อที่แสดงว่าง
- [ ] เทสต์ integration ยิงผ่าน route handler กับ Postgres จริงผ่าน และรันได้ด้วยคำสั่งเดียว
- [ ] มี migration และ seed สำหรับรันระบบบนเครื่อง
