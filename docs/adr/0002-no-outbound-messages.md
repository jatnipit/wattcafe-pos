# ระบบไม่ส่งข้อความออกไปหาลูกค้าเลย

การส่งข้อความทุกชนิดมีต้นทุน: push นับเข้าโควตารายเดือน และ reply token มีอายุเพียง 1 นาที ซึ่งบังคับให้ระบบต้องตอบก่อนที่ร้านจะได้ตรวจออเดอร์ ร้านต้องการควบคุมถ้อยคำเองทั้งหมด จึงตัดการส่งข้อความออกจากระบบ — บอทไม่ reply ไม่ push และไม่แจ้งสถานะ ร้านพิมพ์ตอบผ่าน LINE OA Manager เอง

**Consequences**: ข้อกำหนดเรื่องการแจ้งลูกค้าอัตโนมัติทั้งหมดกลายเป็นหน้าที่ของร้าน ระบบเหลือหน้าที่รับ webhook เก็บข้อความ และแสดงบนกระดานออเดอร์
