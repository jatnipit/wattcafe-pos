# ทุกออเดอร์ต้องผ่านการยืนยันของร้าน ไม่มี auto-confirm

SRS ฉบับร่างกำหนดให้สร้างออเดอร์อัตโนมัติเมื่อระบบ "มั่นใจ" แต่ร้านต้องการเห็นข้อความจริงเทียบกับราคาก่อนทุกครั้ง ระบบจึงจับคำที่ตั้งราคาจากข้อความแล้วเสนอเป็นออเดอร์ร่าง ให้ร้านแก้เมนูและราคาได้ก่อนกดยืนยัน — ไม่มีแนวคิด confidence และไม่มีออเดอร์ใดเกิดขึ้นโดยไม่มีคนกด

**Consequences**: ข้อความที่จับคำไม่ได้เลยจะไม่สร้างออเดอร์ แต่ไปอยู่ในกล่องข้อความเข้าแทน กระดานออเดอร์จึงมีแต่รายการที่ร้านต้องลงมือตรวจ
