# ล็อกอินด้วย Google ผ่าน Supabase Auth และจำกัดด้วยบัญชีที่สร้างล่วงหน้า

Supabase ไม่มี username login และเอกสารทางการแนะนำไม่ให้ปลอมอีเมลรูปแบบ `<username>@fakedomain` เราจึงใช้ Google เป็นผู้ยืนยันตัวตน ปิดการสมัครใหม่ และให้ Super Admin สร้างบัญชี Staff ล่วงหน้าด้วยอีเมลโดยไม่ส่งอีเมลใด ๆ เมื่อผู้ใช้ล็อกอินด้วย Google ครั้งแรก Supabase จะเชื่อม identity เข้ากับบัญชีที่สร้างไว้

**Consequences**: Staff ทุกคนต้องมีบัญชี Google และระบบต้องตรวจสิทธิ์ซ้ำที่ชั้นแอปเพราะเอกสารไม่ได้ยืนยันชัดว่า OAuth เคารพสวิตช์ปิด signup ทุกกรณี; Supabase Free ตั้ง session timeout ไม่ได้ หากต้องการให้หลุดเองต้องทำที่แอป
